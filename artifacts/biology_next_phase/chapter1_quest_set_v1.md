# Chapter 1 Quest Set v1 — 25 high-quality Sonoran quests

Sonoran-grounded, biology-grounded, exploration-first, child-friendly
(Sierra tone), tagged per `quest_taxonomy.md`. These conform to the
generation rules: predict-and-above majority, no dead-end facts (Observe
quests link forward), safety on toxic species, cultural facets GATED.
Tag line legend: **H**=hierarchy primary(+secondary) · **R**=reasoning ·
**G**=gameplayType · **D**=difficulty(grade/challenge/track) ·
**Bio/Eng**=domains · **→**=successor/seeds.

They roughly follow the Act-1 loop (settle in → read the desert → gather
& test → build the bridge → earn trust → open the wider map).
