# NPC Voice Registry Design (Phase 9)

Design only — **no audio generated.** Extends the existing
`src/game/phaser/audio/NPCVoiceRegistry.js` (7 profiles, already wired) into a
production registry for local-TTS pre-bake. Each NPC maps to a stable `voiceId`,
language(s), engine, and a cultural-gate flag. Generation happens only after an
operator authorizes it and the cultural gate clears.

## Per-line generation contract (when built)
For each dialogue line in `act1Dialogue.js`:
```
input : { speaker, text, voiceId, language, emotion, speechEnabled }
  → SpeechNormalizationSystem(text)
  → engine.generate(voiceId, normalizedText, language, emotion)   [GPU1, resource-gated]
  → acceptance: whisper(transcribe)==text? language==expected? librosa(duration>0, no clip, not empty)?
  → if pass: cache  public/game/audio/voice/<voiceId>/<lineId>.ogg  + manifest row
  → if fail: reject (promotion gate), log, do not ship
output: cached clip + manifest { lineId, voiceId, path, lang, durationMs, checksum }
```

## Identity rules
- **One seed per voiceId, registered once**, reused for every line and every act
  → consistent NPC identity (the reason to prefer a cloning engine like XTTS).
- `emotion` field modulates prosody, not identity.
- Bilingual NPCs (Mrs. Ramirez) use the **same seed** across languages for
  recognizability.

## Cultural gate (non-negotiable)
- **Auntie Mariam (Arabic)** and any future voice carrying cultural/linguistic
  identity require **human CARE review before generation** per
  `creative_pipeline_policy.yaml:65-69` ("no agent-authored cultural identity").
- Spanish (Mrs. Ramirez) gets a lighter dialect-respect check.
- This gate is a **hard stop** in the workflow — the registry marks it; the
  pipeline blocks until a human clears it.

## Reuse note
This registry is a **superset of the data already in `NPCVoiceRegistry.js`** — it
adds engine + seed + cultural-gate fields. No new registry system is needed; the
existing one is extended. Speaker→voiceId resolution already works and is tested
(`game-rebuild.audio.spec.js:36-58`).

**No audio is generated by this document.** It defines *what would be generated*
once authorized.
