# Bike Builder: reuse research (what already exists that we can legally use)

Prepared 2026-11-26 (America/Phoenix). Every link below was opened from the box on that date and returned HTTP 200, except where marked. Not legal advice. "Facts aren't copyrightable" is the general US rule (Feist v. Rural, 1991). It doesn't cover copying a document's selection and arrangement, PDFs, images or prose.

## Not usable (checked)

- **BikePartPicker.net** https://bikepartpicker.net/terms/: the terms grant only "personal, non-commercial transitory viewing". They forbid copying, public display, scraping and automated access to its catalogue and compatibility data. There's no public API. It's a competitor to learn from, not a source.
- **Geometry Geeks** https://geometrygeeks.bike/: "open-access" to browse, but there's no data license or API, and advanced search is paid. (Fetch timed out from the box. Read through search results.)
- **99 Spokes** https://99spokes.com/data: paid subscription data and API, contact sales. (Returned 403 to curl. Read through search results.)
- **Sheldon Brown** https://www.sheldonbrown.com/cribsheets.html: print is fine, but reproduction needs credit and a link, and the gear calculator is copyrighted. Link to it from the kid lessons instead of copying.
- **BecSpec, GearGrindr, RideLab, builder.bike**: calculators with no data license found. Reference only. (builder.bike returned 500.)
- **Open e-bike motor/battery database**: none found with an open license. Extract from Bafang/Bosch/Shimano spec PDFs (facts + citation) and the bike-part-planner e-bike module.

## Ingestion pattern (all sources)

1. Write a fetch script per source into `data/builder/raw/` (gitignored for PDFs, never committed).
2. AI-assisted or scripted extraction into category JSON. Each value carries `source_url`, `source_ref` (page/table), `quote` (one short line or less), `checked_at` and `license`.
3. Human review flips `review_status: draft → approved`. Only approved parts appear in the builder.
4. A `ATTRIBUTION.md` and an in-app "Data sources" footer list every CC BY / MIT source.
