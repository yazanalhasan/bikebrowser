# Act 1 Final Art Direction

Date: 2026-05-27

## Core Direction

Act 1 should look like a warm top-down Sonoran neighborhood adventure where every object has a reason to exist. The visual style is sparse, tactile, child-readable, and authored.

The art should make the child feel:

- I am Zuzu.
- This is my neighborhood.
- The garage is safe and creative.
- The bridge problem matters.
- Testing objects changes what I know.
- My notebook belongs to me.

## Palette

Base dusk:

- deep green shadow: `#30473d`
- soft sage: `#405c42`
- muted road blue-gray: `#26343b`
- sidewalk blue-gray: `#55646d`

Warm anchors:

- garage amber: `#f2c46d`
- notebook paper: `#fff0c7`
- terracotta roof: `#b46b45`
- clay wall: `#6f4b38`

Desert accents:

- dry wash tan: `#a78b76`
- rock gray-brown: `#7f7369`
- palo verde/mesquite green: `#4f9c75`
- creosote green: `#7fb069`

Interaction accents:

- turquoise clue/inspection: `#8ed6c9`
- warm quest marker: `#f7c46d`
- success green: `#8bb09a`

Avoid:

- neon UI
- saturated toy plastic colors
- beige-only desert
- dark unreadable green fields
- purple/blue gradient dominance

## Silhouette Philosophy

All interactables must read from shape first.

Zuzu:

- bright shirt block
- compact explorer stance
- readable head and feet
- small shadow
- bottom-center anchor

NPCs:

- each has a distinct shoulder/head/pose silhouette
- color accent matches role
- one small role cue only, not costume clutter

Tools:

- UTM reads as a press/test rig
- chemistry reads as mixing/drying surface
- garage reads as creative workbench cluster
- bridge reads as broken/repaired from thumbnail scale

## Composition Philosophy

The scene should have three primary anchors:

1. Zuzu/home/NPC social start.
2. Garage/workbench/UTM creative heart.
3. Bridge/wash/map-gate emotional problem and payoff.

Roads and paths support movement, but must not become the main visual subject.

## Environmental Rhythm

Use quiet alternation:

- house/home cluster
- social NPC cluster
- garage/tools cluster
- open traversal space
- wash/bridge destination
- wider map hint

Avoid evenly spaced station dots. Each area needs a slightly different silhouette rhythm.

## Landmark Hierarchy

Highest:

- bridge/dry wash
- garage/workbench
- Zuzu/player
- notebook UI

Medium:

- NPCs
- UTM
- chemistry
- ecology patch
- map gate

Low:

- road markings
- decorative plants
- house background

## NPC Visual Language

Mr. Chen:

- calm, grounded, practical
- small tool cue
- steady posture
- warm work colors

Mrs. Ramirez:

- neighbor warmth
- open, welcoming posture
- terracotta/soft green accent
- Spanish context is relationship-based, not a costume

Auntie Mariam:

- gentle mentor/family presence
- cool/warm balanced palette
- cultural specifics should remain restrained until human-authored brief

Trader:

- practical material helper
- sample bag/table association
- no caricature marketplace styling

## Notebook Visual Language

Notebook should feel handmade:

- cream paper
- taped clue cards
- small sketch marks
- hand-labeled tabs
- star/new clue marker
- short evidence snippets

Do not make it:

- spreadsheet-like
- inventory-grid-like
- dense quest log
- fake parchment fantasy UI

## UTM Visual Identity

The UTM is the first serious scientific instrument.

It should:

- look sturdy but simplified
- show sample placement
- show pressing/compression or pull/tension
- animate material response
- produce a clear result cue

It should not:

- look like a lab dashboard
- rely only on bars/text
- become a disconnected minigame

## Bridge Visual Identity

Broken bridge:

- clearly unsafe
- gap visible
- flood/wash context visible
- not scary or catastrophic

Repaired bridge:

- visibly stronger
- triangular support readable
- crossing path open
- warm success cue

The child should understand before/after at screenshot scale.

## Garage / Workbench Identity

The garage is the emotional heart:

- warm light
- organized tools
- bike/repair language
- a safe maker space
- not cluttered
- not sterile

It should invite the child to return.

## HUD Philosophy

Normal HUD:

- one story hint
- one current clue
- notebook affordance
- no raw counters/trust/debug state

Debug HUD:

- F3 only
- raw state is allowed there

HUD should support the world, not replace it.

## Production Rule

Final runtime art must be Aseprite-authored or Aseprite-cleaned and loaded through AssetRegistry with placeholder fallback. Generated concept art is reference only.
