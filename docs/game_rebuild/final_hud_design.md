# Final HUD Design

Goal: HUD should feel like trail guidance, not a debug panel.

Changes:

- Trail card gained warmer border, paper glow, trail dot, and path line.
- Existing tests still require child-facing text and reject debug glyphs.
- Debug scene remains hidden by default.
- Evidence panel remains compact and clue-focused.

Remaining:

- Bottom help text is still utility-like. It remains because it supports playability, but future icon-based control hints would feel warmer.
