# Inventory Recipe System Report

Lane: Notebook-Inventory-Agent
Scope: Phase 8 Act 1 inventory and small recipe combinations only.

## Implemented

- Expanded canonical Core/InventoryManager/InventoryManager.gd instead of enabling the generated inventory addon as a second authority.
- Added visible Act 1 starter inventory:
  - Field Notebook
  - Wrench
  - Chain Lube
  - Inner Tube
  - Patch Kit
  - Copper Ore
  - Water Test Strip
  - Plant Sample
- Added learned recipe state and public APIs:
  - learn_recipe(recipe_id)
  - is_recipe_learned(recipe_id)
  - combine_items(first_item_id, second_item_id)
  - craft_recipe(recipe_id)
  - get_inventory_snapshot()
  - get_item_cards()
  - get_recipe_cards()
  - get_learned_recipe_cards()
- Added EventBus.inventory_updated(snapshot) and EventBus.recipe_feedback(message, tone).
- Added quest-objective hooks through existing quest_step_completed signal:
  - inner_tube + patch_kit -> Ready Inner Tube, learned from flat_tire_repair:apply_patch.
  - copper_ore + water_test_strip -> Copper Evidence Note, learned from copper_rock_id:test_conductivity.
  - plant_sample + field_notebook -> Plant Observation Note, learned from desert_plant_observation:journal_observations.
- Added reward item intake through existing reward payloads so capstone rewards become visible inventory items:
  - Regional Travel Sketchbook
  - Spacecraft Clue Card

## Player Feedback

- Recipes refuse crafting before they are learned and emit child-readable feedback through the HUD hint line.
- Missing ingredients are reported by readable item name.
- Successful combinations add the resulting item/note and save through the canonical Godot save key.

## UI

- The inventory panel is generated by the existing HUD:
  - Toggle with I.
  - Touch/click button in the small HUD toggle bar.
  - Shows visible item cards and recipe cards.
  - Locked recipes include the learning hint instead of silently failing.
