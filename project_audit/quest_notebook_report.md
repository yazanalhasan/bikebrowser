# Quest Notebook Report

Lane: Notebook-Inventory-Agent
Scope: Phase 7 in-world quest notebook only. No Act 2 expansion and no new regions.

## Implemented

- Added a canonical notebook snapshot API on QuestRegistry.get_notebook_snapshot().
- Integrated the notebook with existing stable quest, inventory, discovery, and reward surfaces:
  - quest_started
  - quest_step_completed
  - quest_completed
  - InventoryManager.get_learned_recipe_cards()
- Added EventBus.notebook_updated(snapshot) so UI can refresh without owning plant, water, or mechanic quest logic.
- Added a warm field-notebook panel to the existing HUD, generated by Systems/UI/HudController.gd:
  - Toggle with N.
  - Touch/click button in the small HUD toggle bar.
  - Escape closes the panel.
  - Modal guard is pushed only while the overlay is open.
- Notebook pages currently show:
  - Current objective and gentle hint.
  - Completed and active quest-derived knowledge.
  - Learned mechanics from tire, chain, brake, water, and copper objectives.
  - Discovered plants and materials when their existing objectives are recorded.
  - Learned recipes from inventory.
  - Sketches/notes from tire, chain, plant, and capstone objectives.
  - Capstone clues once Act 1 readiness is available or complete.

## UX Notes

- The HUD remains minimal by default: only two compact notebook/inventory buttons are added under the current objective panel.
- The notebook uses warm paper colors, sketchbook-style cards, readable 13-18 px text, and scroll containers for keyboard/touch accessibility.
- No new region content or quest logic was added. Plant, water, copper, tire, chain, brake, and capstone content is reflected through existing objective IDs.
